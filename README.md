# WiFi Network Map

A Linux-based network discovery and visualization tool.

## Features

- Discover devices on a local network
- Collect IP addresses
- Collect MAC addresses
- Identify network interfaces
- Detect the default gateway
- Identify device hostnames
- Generate a network topology map
- Monitor devices in real time
- Provide a web-based network dashboard

## Technology

- Python
- Linux
- Nmap
- Scapy
- NetworkX
- PyVis
- Flask
